Slice 1 textures: part types and candidates

A first pass in the three settled materials, with no new material and no new colour. Layout is the wireframes'. Data is the demo set's.

Part types, as aluminum tape Settled. A part type is a name you press, so it is the second tape: embossing tape in the plate's metal, in its own case. The strip above it is a name that does nothing, and stays black. The lines from Vehicle and Model year run on down from the names to a strip saying what was asked.

Candidates, as parts tags on two rails Settled. A candidate is a thing the page hangs. Its number is a strip of tape across the tag, where a card prints its group's band. Two rails of pinstripe run from the pressed part type to every tag: Vehicle's blue and Model year's orange, since a part fits a model in certain years.
